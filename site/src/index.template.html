KubeCompass

A Kubernetes client for the Mac. Its topology map says how it knows each line it draws.

Every relationship is tagged Observed, Declared, Inferred or Unavailable. When an input is missing, the map says so instead of drawing it as complete.

No published release yet. Build it from source on macOS 26 or later.

Note 2

What it cannot see

Traffic. Without a telemetry adapter, traffic shows as unavailable.

Selectors and Ingress backends are configuration, not proof of traffic. The project’s decision record says the same.

The topology view is read-only. Secret and ConfigMap payloads are never listed for topology.

Note 3

How it runs

KubeCompass drives a bundled kubectl and your kubeconfig, so the auth plugins you already use keep working.

App Sandbox is off, because the app reads ~/.kube and starts kubectl. The updater is off until a release feed exists.
