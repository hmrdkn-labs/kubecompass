What the map will not guess

Traffic is unavailable without a telemetry adapter, and the map says so instead of drawing it.

Selectors and Ingress backends are configuration, not proof of traffic. The project’s decision record says the same.

The topology view is read-only. Secret and ConfigMap payloads are never listed for topology.

Runs on the access you already have

  • Your kubeconfig, your auth plugins

    KubeCompass drives a bundled kubectl and your kubeconfig, so the auth plugins you already use keep working.

  • App Sandbox is off

    The app reads ~/.kube and starts kubectl, so App Sandbox is disabled.

  • No updater yet

    The updater is off until a release feed exists.

  • Linux runs on fixture data only

    The Linux adapter reads no kubeconfig and runs no kubectl.

Build it yourself

No published release yet. Build it from source on macOS 26 or later. The documented build turns code signing off.

xcodebuild -project k-dex.xcodeproj -scheme k-dex \
  -configuration Release -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO build

The README lists what is still unverified: accessibility, frame rate and memory use, and live-cluster checks.
